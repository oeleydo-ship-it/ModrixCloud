# Order Returns

Customers ask to send items back. Staff approve or reject that request and leave a comment the customer can read on the order. The request does not refund money or change stock.

## Settings

On the extension page:

| Setting                      | Effect                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------- |
| Return window (days)         | How long after delivery, or after shipping, a request is accepted. Default 30.  |
| Orders can be returned after | Delivered, or shipped (which also includes delivered orders).                   |
| Minimum comment length       | Used for the customer's reason and for the staff comment on approve and reject. |

## Customer

The form appears on the signed-in customer's order page when the module is enabled. Their account menu also has a Returns tab that lists every request they have made, including the store's comment. They choose quantities and write why. One request can be waiting at a time. Approved quantities cannot be requested again. A rejected request frees those quantities.

## Staff

Admin → Sales → Returns opens the review page. A left sidebar switches between waiting, approved, and rejected requests. Approve and reject each require a comment. The order's payment and fulfillment stay as they were.
