# Marketplace Electronics

Reference-inspired, unbranded electronics theme with Manrope typography, editable campaigns and promotional tiles, catalog filters and product layouts. All theme colors, navigation, footer content and home sections are configurable in Appearance → Customize.

The default Reference page width centers a 1,280px content column on desktop. Header, home sections, catalog, product details and footer share that alignment; smaller screens retain responsive gutters. Catalog and product rail backgrounds may extend across the viewport while their content remains centered.

Reference product photography was supplied from the user-requested Jumbo reference URLs. No Jumbo logos, trade names or marketing text are included. Manufacturer marks may remain in product photography. Manrope is distributed under the SIL Open Font License; see FONT-LICENSE.txt.

Demo products are optional and are only imported through the existing explicit demo import control. Existing products are never overwritten.
