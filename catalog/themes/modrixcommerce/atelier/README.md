# Atelier — Editorial Storefront

An editorial luxury minimalism storefront theme for Modrix, inspired by the Atelier design on MagicPath.

## Highlights
- **100% Live Customizer**: Every heading, banner, button, typography scale, palette token and spacing can be edited without code changes.
- **Section Architecture**: Full native sections v2 support with custom templates for home, catalog, search, product, cart, and editorial CMS pages.
- **Editorial Proportions**: Balanced split hero, considered essentials shelf, storytelling blocks, curated gift edit, and immersive campaign banners.
- **Integrated Extension Slots**:
  - `header.actions`
  - `product.card`
  - `product.after_title`
  - `product.after_price`
  - `product.after_add_to_cart`
  - `product.after_description`
  - `catalog.before_products` & `catalog.after_products`
  - `cart.after_lines`
  - `storefront.footer`
  - `apps`
- **Zero Hardcoding**: All labels, CTA texts, image links, options, and layout behaviors are prop-driven with editorial defaults.
