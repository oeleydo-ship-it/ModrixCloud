# Relay Electronics

A technology storefront built for Modrix Commerce’s current section customizer. The MagicPath design follows the supplied technology-store reference with independent Relay branding and original unbranded photography.

## Install and customize

Install this package in Appearance → Themes, then Preview or Customize. Activate when ready. Import demo content only into a store where you want its 26 sample products, six collections and two sample pages. Existing catalog items are not overwritten.

Use the live editor’s Header, Footer, Homepage, Product, Collection, Search, Cart and Page templates. Sections and blocks can be added, reordered and disabled. Hero copy/photo/size/colors, promotion cards, category tiles, shelf collections/counts/category links, navigation, footer columns/social/payment blocks and service text are editable. Choose an actual collection on each product shelf; a new shelf falls back to the latest catalog products.

Header and Footer → Menus can follow Admin → Navigation once merchant menus are saved. Choose Theme to keep section-owned links, or Store to always use the saved store menus. Phone layouts use the bottom Categories tab in place of the blue desktop strip.

Theme settings control colors, body and heading fonts, container width and text sizes. Header → Sticky header keeps the native header pinned on desktop and mobile. Compact header while scrolling hides the blue category strip once scrolled and restores it near the top. Mobile Menu, Categories, Search and Cart navigation uses accessible dialogs, real category trees, live search and the actual cart.

Deal countdowns use the configured Offer end ISO date with timezone (for example 2027-01-01T23:59:59+04:00). Leave it empty to hide the countdown; no artificial deadline or sales counters are shown. Product prices, availability, labels, sale notices, variants and images come from the catalog.

## Customer and commerce features

Customer login, registration, password recovery/change, account/order pages, cart and checkout retain the platform shell and theme typography. Product galleries, quantity limits, selected variant prices, Add to cart and Buy now use native commerce actions. Wishlists and comparisons are stored on the shopper’s device; they are not synced to an account.

Enabled module widgets render through the public extension contracts. Product offers appear in a wide panel after the purchase area; after-details modules follow the description. Modules placed below the description appear in the editable Reviews & details tab. Review stars and review counts require real review data; the theme does not invent ratings. Configure optional modules through their own admin screens and Extension blocks in the customizer. See MODULES.md and module-compatibility.json. Gateways and external services still require merchant credentials and configuration.
