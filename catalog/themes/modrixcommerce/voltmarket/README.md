# Volt Market

A new, independently branded marketplace theme inspired by the layout of https://martfury.botble.com/ and the supplied references. The MagicPath designer prototype (component 469559860304953344, revision 469562888890245120) was built and visually checked before integration. Theme assets are bundled; see assets/CREDITS.md for Unsplash photography and the bundled font licence.

## Customize

Open Appearance → Volt Market → Customize. Uses the current native section editor, with six page templates, header/footer groups, reorderable sections and blocks. Theme settings include global colors and uploaded/custom fonts; section settings include every campaign image, heading, button destination, shelf collection, filter visibility and footer content. Header navigation can use its own editable blocks or the store menu, including nested dropdowns.

## Mobile navigation

On screens up to 767px wide, a fixed Menu / Categories / Search / Cart bar opens separate panels. Categories use the platform’s active category tree; plus/minus buttons expand subcategories while category names open the catalog. Search submits to the real store search and the cart count updates with the cart. The panels support Escape, outside-click dismissal, focus management and independent scrolling. The Header section controls visibility, labels and the active color. Desktop navigation is unchanged.

## Store features

Real server catalog/search, brand/price/stock/variant filters, sort and pagination; variant-aware gallery and quantity; platform cart and Buy now checkout. Wishlist and up-to-four-product comparison stay on the current device. Reviews, promotions, add-ons and newsletter are rendered through platform extension slots when enabled. No invented customer reviews or payment-provider claims are included. Add the Customer stories section only for real testimonials.

Optional demo import is namespaced and idempotent. Replace demonstration specifications and configure store policies/contact details before selling. The theme is registered separately and does not replace the active theme until activated.

Sticky header: enabled by default on desktop and mobile. In the live customizer, open the Header section and toggle Sticky header. The theme’s own logo, search, navigation and module actions remain visible; announcement banners scroll away.
